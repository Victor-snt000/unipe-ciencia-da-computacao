# Desenvolvimento Front-End para Web

**Professor:** Israel Cunha

Disciplina voltada à criação de interfaces web modernas, interativas e responsivas, indo dos fundamentos da web até técnicas mais avançadas de desenvolvimento.

## Conteúdo programático

- **Fundamentos da web:** protocolos HTTP/HTTPS, HTML5 semântico, formulários e recursos multimídia
- **CSS3:** sintaxe, layouts com Flexbox e Grid, estilização de componentes
- **JavaScript (ES6+):** manipulação do DOM, eventos, armazenamento local, integração com Bootstrap
- **Versionamento e deploy:** Git/GitHub, engenharia de prompt com IA, acessibilidade web, configuração de ambiente
