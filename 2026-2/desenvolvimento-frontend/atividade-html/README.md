# Atividade HTML - Desenvolvimento Front-End para Web

Atividade de HTML da matéria **Desenvolvimento Front-End para Web**, feita na
faculdade UNIPÊ, no 2º período de Ciência da Computação.

## Sobre

Projeto com 12 páginas HTML, cada uma explorando uma tag ou conjunto de tags
vistas em sala com o professor Israel Cunha. Todas as páginas compartilham um
menu de navegação (`<nav>`) que permite ir de qualquer página para qualquer
outra.
